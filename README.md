# RSRS 择时指标复现与实证检验

**复现对象**：光大证券金融工程研究报告《基于阻力支撑相对强度（RSRS）的市场择时》（2017-05-01）
**标的**：沪深300 指数（附上证综指、深证成指作稳健性对照）
**样本区间**：2005-04-08 至 2024-12-31
**数据频率**：日频

---

## 摘要

RSRS 择时指标在沪深300 全样本区间内实现年化收益 7.94%，同期指数买入持有为 7.44%，
年化超额收益 0.49%；策略最大回撤 -46.38%，较买入持有的 -72.30% 收窄 25.92 个百分点，
Calmar 比率由 0.10 提升至 0.17。全区间累计触发 146 次仓位切换。

分年度来看，指标的超额收益集中于下行行情：2008、2011、2018 等系统性下跌年份取得正
超额；2006—2007、2009、2019 等单边上行年份为负超额，原因是信号相对价格趋势存在
滞后。该结果与原始报告"趋势市有效、震荡市磨损"的结论方向一致。

---

## 一、指标定义

对指数日频最高价与最低价构建滚动最小二乘回归：

```
high_t = α + β · low_t + ε_t
```

回归窗口 N = 18 个交易日，斜率 β 即 RSRS 原始值，衡量最高价对最低价的敏感程度：
β > 1 表示高点抬升快于低点，对应上行趋势；β < 1 反之。

将 β 按过去 M = 600 个交易日的均值与标准差标准化：

```
z_t = ( β_t − mean(β) ) / std(β) ,   窗口 = [t − M + 1, t]
```

交易规则如下，采用状态记忆机制，仅在穿越阈值时改变仓位：

| 条件 | 目标仓位 |
|---|---|
| z > +0.7 | 1（满仓） |
| z < −0.7 | 0（空仓） |
| 其余 | 维持上期仓位 |

## 二、数据与回测设定

| 项目 | 设定 |
|---|---|
| 数据来源 | 腾讯行情接口日频 OHLC；`_fetch_data.py` 可重新获取 |
| 信号时点 | t 日收盘（计算需用到当日最高价与最低价） |
| 成交时点 | t + 1 日收盘 |
| 交易成本 | 单边 0.001，按仓位变动金额计提 |
| 基准 | 标的指数买入持有 |
| 仓位约束 | 0 或 1，不加杠杆、不做空 |

前视偏差的处理方式：β_t 仅使用 t 日及之前的最高价与最低价，z_t 仅使用 t 日及之前的 β
序列；由于信号依赖当日最高价与最低价，最早只能在 t 日收盘获得，故成交统一滞后一个
交易日。代码中对 `lag = 0` 的参数直接抛出异常，以规避该类错误。

数据清洗：免费数据源个别交易日的 OHLC 存在内部矛盾（例如 2015-03-27 的最低价高于
收盘价）。`data.py` 以 0.01 点位为容差进行一致性校验，超出容差的记录予以剔除，
本区间剔除 1 个交易日。

## 三、实证结果

**表 1　RSRS 择时绩效（沪深300，2005-04-08 至 2024-12-31）**

| 指标 | 数值 |
|---|---|
| 累计收益 | 327.87% |
| 年化收益 | 7.94% |
| 年化波动 | 15.49% |
| 夏普比率 | 0.57 |
| 最大回撤 | -46.38% |
| Calmar 比率 | 0.17 |
| 日度胜率 | 22.06% |
| 累计仓位切换次数 | 146 |

注：空仓日的收益记为 0 并计入胜率分母，故该指标对择时策略天然偏低，不宜与纯多头
策略的胜率直接比较。

**表 2　与买入持有基准的对比**

| 指标 | RSRS 择时 | 买入持有 | 差额 |
|---|---|---|---|
| 累计收益 | 327.87% | 292.14% | +35.73 |
| 年化收益 | 7.94% | 7.44% | +0.49 |
| 最大回撤 | -46.38% | -72.30% | +25.92 |

注：差额单位为百分点；基准的年化波动与夏普比率未在表中列示。

**图 1**　见 `report/rsrs_sh000300.png`，自上而下依次为指数走势与开平仓信号、
RSRS 标准分与阈值、策略与基准净值及回撤。

## 四、与原始报告结论的对照

原始报告未公开完整参数网格与精确样本区间，因此本报告不逐项对齐数值，仅对照定性结论：

| 原始报告结论 | 本次复现 |
|---|---|
| 可显著降低回撤 | 成立，最大回撤由 -72.30% 降至 -46.38% |
| 存在正向超额收益 | 成立，但幅度有限（年化 +0.49%） |
| 趋势市表现优于震荡市 | 成立，下跌年份正超额、单边上行年份负超额 |
| 信号频率低、成本可控 | 成立，全区间 146 次仓位切换 |

## 五、局限

1. 成交价采用 t + 1 收盘，相对开盘成交口径略偏乐观；开盘成交口径的对照检验见项目
   `rsrs-improved`；
2. 交易成本按固定费率计提，未建模冲击成本与组合容量约束；
3. 标准化窗口 M = 600 需累计约 618 个交易日的历史，2005-04 至 2007 年三季度末为窗口
   预热期，期间无有效信号，仓位恒为 0；
4. 回测基于价格指数点位本身，实盘需通过 ETF 或股指期货实现，将引入跟踪误差、基差与
   保证金占用等额外摩擦；
5. 标的为价格指数，未计入分红再投资收益。

## 六、复现说明

```bash
pip install -r requirements.txt

python run.py                     # 沪深300，默认参数 n=18、m=600、阈值 ±0.7
python run.py --symbol sh000001   # 上证综指
python run.py --n 24 --m 600 --s-buy 1.0 --s-sell -0.7
python tests/test_rsrs.py         # 单元测试
```

全部参数均通过命令行显式传入，未设置隐含默认值。
