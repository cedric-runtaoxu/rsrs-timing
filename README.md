# RSRS 择时指标复现（光大证券）

用 Python 复现光大证券金融工程研报《基于阻力支撑相对强度（RSRS）的市场择时》，
并在真实指数日行情（沪深300 / 上证综指 / 深证成指，2005–2024）上做完整回测。

> 这是券商金工组求职作品集的一部分：完整走一遍「读报告 → 写成可执行规格 →
> 实现 → 回测 → 与报告结论对比 → 写清楚局限」。

## 一句话结论

RSRS 择时在 **20 年全样本上相对买入持有只有约 +0.5%/年的超额**，但**最大回撤从
-72% 降到 -46%**。它不是一个高夏普的「印钞机」，而是一个**控回撤、躲熊市**的
择时工具 —— 这与原报告「RSRS 在趋势市有效、震荡市磨损」的定性结论一致。

| 指标 | RSRS 择时 | 买入持有 |
|---|---|---|
| 累计收益（2005-04 ~ 2024-12） | **327.9%** | 292.1% |
| 年化收益 | **7.94%** | 7.44% |
| 年化波动 | 15.49% | — |
| 夏普比率 | 0.57 | — |
| 最大回撤 | **-46.4%** | -72.3% |
| 交易次数（一次买/卖切换） | 146 | — |

## RSRS 是什么

对指数每日的最高价 `high` 与最低价 `low` 做滚动 OLS：

```
high = alpha + beta * low + eps
```

- 斜率 `beta` 就是「最高价相对最低价的敏感度」；
- 上涨市中高点抬升快于低点 → `beta > 1`；下跌市反之 → `beta < 1`；
- 把 `beta` 用过去 `M` 日的均值 / 标准差标准化，得到 `z`；
- `z > +S` 满仓，`z < -S` 空仓，否则维持。

它捕捉的是传统技术分析里难以量化的「**支撑与阻力的相对强度**」——不是绝对点位，
而是高、低点之间的**相对**变化速度。

### 关键时间轴（防未来函数）

```
beta_t  只用 t 日及之前的高低点（回归窗口 N）
z_t     只用 t 日及之前的 beta 序列（标准化窗口 M）
信号     在 t 日【收盘】才可知（因为用到了当日高低点）
成交     在 t+1 日（lag=1），本仓库用 t+1 收盘价，更保守可用开盘价
```

代码里 `backtest(lag=0)` 会**直接报错**，防止写出「用当日高低价又当日成交」的未来函数。

## 快速开始

```bash
pip install -r requirements.txt

python run.py                     # 沪深300，默认参数 n=18 m=600 阈值 ±0.7
python run.py --symbol sh000001   # 上证综指
python run.py --n 24 --m 600 --s-buy 1.0 --s-sell -0.7
python tests/test_rsrs.py         # 7 项单元测试
```

产出（`report/`）：指标表、`beta/z/position` 时间序列、净值曲线、回测图。

## 复现结果与对比

原报告（光大 2017-05-01）样本区间与参数公开信息与本复现**不完全一致**
（公开摘要未给出完整参数网格与精确样本），因此这里**不逐项对齐数字**，
只对齐**定性结论**：

| 原报告结论（公开摘要） | 本复现是否印证 |
|---|---|
| RSRS 能显著降低回撤 | ✅ 最大回撤 -72% → -46% |
| 相对买入持有有正的超额收益 | ✅（但幅度小，约 +0.5%/年） |
| 趋势市表现更好、震荡市磨损 | ✅ 分年度看 2008/2011/2018 等熊市年大幅跑赢，2007/2019 等单边牛市跑输 |
| 信号频率低、交易成本可控 | ✅ 20 年仅 146 次切换（约 3.7 次/年） |

**本复现的已知局限**：

1. 成交价用 `t+1` 收盘（略乐观），更保守的 `t+1` 开盘成交见姊妹项目 `rsrs-improved`；
2. 成本用固定 0.1% 单边，未建模冲击成本；
3. `M=600` 的标准化窗口意味着**前约 600 个交易日（2005-04 ~ 2007 上半年）无信号**，
   分年度表里 2005、2006 为空仓是预热期，不是策略判断；
4. 免费数据源个别交易日存在取整/错误（如 2015-03-27 的 low 明显异常），
   加载器会打印并丢弃（本项目丢弃 1 行）。

## 数据与复现性

- 数据源：腾讯行情接口（免费、无需 token），`_fetch_data.py` 可一键重下；
- 建议日常研究换用 Wind / Tushare / 聚宽，并对齐口径；
- 复现一个结果只需：`python run.py --n 18 --m 600 --s-buy 0.7 --s-sell -0.7`，
  所有参数都在命令行显式给出，不藏任何默认魔法。
