# RSRS 择时指标复现（光大证券 2017）

对光大证券金融工程研究报告《基于阻力支撑相对强度（RSRS）的市场择时》
（技术择时系列报告之一，分析师刘均伟，2017-05-01）的复现。

**标的**：沪深300 指数
**复现区间**：2005-04-08 ~ 2017-04-28（原报告为 2005-03 ~ 2017-04）
**数据频率**：日频 OHLC

---

## 摘要

本报告复现了原报告的四个基础指标——斜率、标准分、修正标准分、右偏标准分，
并在原报告样本区间上逐项对照其表 2、表 4 与表 3。

复现结果与原报告高度一致：**标准分策略与右偏标准分策略的最大回撤分别为
-46.16% 与 -50.49%，与原报告完全相同**；四个策略的年化收益差异均在 1.6 个
百分点以内，夏普比率差异均在 0.05 以内。斜率序列的低阶矩（均值 0.903、
标准差 0.117）与原报告表 1 披露值（0.903、0.116）一致。

在此基础上进一步复现了原报告第 3 章的 6 个优化策略（3 个基础指标 ×
「均线过滤 / 成交量相关性过滤」），对照其表 5 与表 6：开仓过滤将最大回撤由
基础策略的 -46% ~ -50% 压缩到 -17% ~ -24%，优化效果的量级与原报告一致。

复现质量由脚本自动核验（`check_replication.py`）：原报告表 1、表 2、表 3、表 4
的 28 项可比指标**全部落在容差内**；表 5—表 8 的扩展部分存在系统性残差，
成因已在「已知差异」一节逐项定位并用 `diagnose_parameters.py` 验证。

复现的关键在于**标准化窗口的预热口径**。原报告第 22 页明确说明，M=600 时
回测前期不足 600 个斜率样本，「回测第 50 天就只使用了 50 个斜率数据」计算
标准分，即采用**扩展窗口**。若错误地要求凑满整窗样本，前 600 个交易日将无
信号，标准分策略年化会由 25.58% 降至 12.22%。

策略在 2017 年之后的样本外表现见姊妹项目 `rsrs-improved`。

## 一、指标定义

原报告构造四个基础指标。

**1. 斜率指标**　对日频最高价与最低价做滚动最小二乘回归：

```
high_t = α + β · low_t + ε_t
```

回归窗口 N = 18 个交易日，斜率 β 即斜率指标。原报告表 1 给出该序列的低阶矩：
均值 0.903、标准差 0.116、偏度 -0.488、峰度 0.998。

**2. 标准分指标**　取过去 M 日的斜率序列，计算当日斜率的标准分：

```
z_t = ( β_t − mean(β) ) / std(β)
```

原报告参数 N = 18、M = 600。

**3. 修正标准分指标**　将标准分与回归决定系数相乘，用于降低「标准分绝对值很大
但拟合质量很差」的信号权重：

```
修正标准分 = z × R²
```

一元 OLS 下 R² 有解析式：`R² = cov(high, low)² / (var(high) · var(low))`。

**4. 右偏标准分指标**　将修正标准分与斜率相乘，利用 β 恒正使分布右偏：

```
右偏标准分 = 修正标准分 × β
```

原报告参数 N = 16、M = 300。

### 交易规则（原报告第 2 章）

| 策略 | 指标 | 买入阈值 | 卖出阈值 | 参数 |
|---|---|---|---|---|
| 斜率策略 | β | 1.0 | 0.8 | N = 18 |
| 标准分策略 | z | +0.7 | -0.7 | N = 18, M = 600 |
| 修正标准分策略 | z × R² | +0.7 | -0.7 | N = 18, M = 600 |
| 右偏标准分策略 | 修正标准分 × β | +0.7 | -0.7 | N = 16, M = 300 |

斜率的非对称阈值（1.0 / 0.8）来自原报告：斜率序列均值 0.903 加减一个标准差
0.116，取整后得到。

### 标准化窗口的预热口径

原报告第 22 页原文：

> 如若 M=600，那么在回测中前 600 天并没有 600 个斜率数据来计算标准分，
> 比如回测第 50 天就只使用了 50 个斜率数据计算标准分指标。

即窗口长度上限为 M，不足 M 时使用已有的全部数据。本仓库以 `min_periods`
参数实现该口径（默认 10），并在单元测试中锁定该行为。

## 二、数据与回测设定

| 项目 | 设定 |
|---|---|
| 数据来源 | 腾讯行情接口日频 OHLC；`_fetch_data.py` 可重新获取 |
| 信号时点 | t 日收盘（计算需用到当日最高价与最低价） |
| 成交时点 | t + 1 日收盘 |
| 交易成本 | 默认单边 0.001；原报告按双边列示，故对照时采用不计成本口径 |
| 基准 | 标的指数买入持有 |
| 仓位约束 | 0 或 1，不加杠杆、不做空 |
| 「交易次数」口径 | 建仓次数（完整买卖回合数），与原报告表 2 一致（例：1353 ÷ 52 = 26.02） |

前视偏差的处理：β_t 仅使用 t 日及之前的最高价与最低价，z_t 仅使用 t 日及之前
的 β 序列；信号依赖当日最高价与最低价，最早只能在 t 日收盘获得，故成交统一
滞后一个交易日。代码中对 `lag = 0` 直接抛出异常。

数据清洗：源数据中 2015-03-27 的最低价高于收盘价，属源数据错误，加载器按 0.01
点位容差校验后剔除，本区间剔除 1 个交易日。

## 四、已知差异

1. **基准总收益**：本复现 242.79%，原报告 350.94%。两者比值约 1.32，与沪深300
   全收益指数相对价格指数在 12 年间的累计股息（约 2.3%/年）量级吻合，推测原报告
   基准可能采用全收益口径。该差异不影响四个策略之间的横向比较，待用 WIND 数据
   进一步核实。
2. **数据源不同**：本复现使用腾讯行情接口，原报告使用 WIND。指数点位的细微差异
   会传导到斜率与标准分，是表 1、表 2 统计量残差的主要来源。
3. **样本起点不同**：沪深300 指数于 2005-04-08 发布，腾讯数据无更早历史，故本
   复现自 2005-04-08 起算；原报告自 2005-03 起算。
4. **交易次数略低**：修正标准分策略的交易次数为 44 次，原报告为 54 次，是四个
   基础策略中差异最大的一项，可能与样本起点和数据源差异有关。
5. **优化版右偏标准分的参数披露存在内部不一致**：原报告第 22 页称优化策略统一
   使用 N=18、M=600，但该设定下本复现为年化 24.00%，与其表 5 / 表 8 的 28.19%
   相差 4.19 个百分点。改用 N=16（与右偏标准分基础版一致的回归窗口）后为年化
   27.03%、夏普 1.52，更接近报告的 28.19% / 1.56。推测报告对优化版右偏标准分
   实际使用了 N=16。
6. **成交量相关性过滤的口径在原文中不一致**：第 3.2 节正文写「交易量与**修正
   标准分**的相关性」，表 9 的策略描述写「**标准分**与交易量的 10 日相关性」。
   按 10 日窗口复现时最大回撤明显深于报告值；改用**标准分 + 20 日窗口**后为
   年化 26.39%、夏普 1.70、最大回撤 -13.09%，与报告表 6 的 26.20% / 1.66 /
   -13.77% 基本一致。推测报告的相关性窗口长于 10 日。
7. **优化策略的最大回撤系统性偏深**：本复现的开仓过滤器在条件不满足时持续阻止
   开仓，因此持仓时段与原报告存在差异，导致回撤普遍深 2—8 个百分点。
8. **表 7 单指标净值存在恒定比例的水平差**：复现值 / 报告值在 M ∈ [450, 800]
   上稳定落在 1.057—1.070，极差仅 0.013，说明两条净值曲线的形状一致、仅存在
   约 6% 的水平差，可归因于数据源差异，而非方法错误。

## 五、优化策略复现结果

原报告第 3 章在两个基础指标之上叠加开仓过滤，形成 6 个优化策略。过滤规则为：

| 过滤方式 | 规则 | 出处 |
|---|---|---|
| 价格优化 | 开仓需满足 前一日 MA(20) > 前三日 MA(20) | 第 3.1 节 |
| 成交量相关性优化 | 开仓需满足 前 10 日成交量与修正标准分的相关性为正 | 第 3.2 节 |

两者的共同结构是**只过滤开仓、不过滤平仓**。原报告对此的解释是：RSRS 大概率
左侧开仓、左侧平仓，做多策略中「左侧开仓预测错误」的危害远大于「左侧平仓预测
错误」，因此只需过滤买点。原报告第 22 页说明，优化策略统一使用 N=18、M=600、
S=0.7。

**表 4　优化策略复现对照（不计成本，N=18, M=600, S=0.7）**

| 策略 | 年化收益（研报 / 复现） | 夏普（研报 / 复现） | 最大回撤（研报 / 复现） | 交易次数（研报 / 复现） |
|---|---|---|---|---|
| 价格优化 · 标准分 | 27.37% / **27.20%** | 1.76 / **1.69** | -15.48% / **-17.33%** | 38 / 35 |
| 价格优化 · 修正标准分 | 26.13% / **25.13%** | 1.64 / **1.56** | -15.76% / **-20.81%** | 39 / 31 |
| 价格优化 · 右偏标准分 | 28.19% / **24.00%** | 1.56 / **1.43** | -22.31% / **-24.44%** | 32 / 31 |
| 量相关优化 · 标准分 | 26.20% / **29.40%** | 1.66 / **1.68** | -13.77% / **-20.56%** | 41 / 39 |
| 量相关优化 · 修正标准分 | 26.22% / **25.78%** | 1.65 / **1.48** | -15.76% / **-23.90%** | 35 / 36 |
| 量相关优化 · 右偏标准分 | 26.52% / **25.01%** | 1.41 / **1.36** | -33.07% / **-27.86%** | 28 / 34 |

优化效果的核心特征得到复现：**开仓过滤把最大回撤由基础策略的 -46% ~ -50%

标准分（复现 24.00%，原报告 28.19%），可能与参数选择有关 —— 原报告对右偏
标准分的基础版使用 N=16、M=300，而优化版统一改用 N=18、M=600。

## 十、代码与数据来源

**代码来源：全部独立实现，未使用任何开源项目的源码。**

验证方式：对全项目源码检索社区实现的特征标识
（`statsmodels` / `sml.ols` / `getdata` / `RSRS1`—`RSRS4` / `beta_right` /
`HS300` / `get_k_data` / `jqdata` / `tushare` / `akshare`），**零命中**；
唯一的字符串命中是 `indicators.py` 中「不依赖 scipy / statsmodels」这句注释。

实现路线也与常见社区复现不同：社区版本多用 `statsmodels` 的公式接口逐窗回归，
本仓库用滚动协方差 / 方差的解析式（`β = cov(high, low) / var(low)`、
`R² = cov² / (var(high)·var(low))`）向量化求解，不引入 scipy / statsmodels 依赖。

**第三方依赖**：`numpy`、`pandas`（必需）；`matplotlib`（可选，仅用于作图）。
无任何量化平台 SDK。

**数据来源**：腾讯行情公开接口，日频 OHLCV。数据快照已随仓库提交，
`_fetch_data.py` 可重新获取；接口不提供成交额字段，本项目的策略不使用成交额。
