# 研究结构与运行协议

## 主研究：按原研报逐章复现

入口`python paper.py`，配置`rsrs/paper_study.py`中的PAPER_SPEC，结果`report/paper/report.md`。

1. 第1章：传统支撑阻力阈值策略、市场状态示意、高低价OLS与RSRS构造。
2. 第2章：斜率分布、阈值、基础回测、交易质量、成本、N扫描；2008问题与2009—2014行情；R²和右偏修正、原文式未来10日分箱预测性。
3. 第3章：价格过滤、成交量过滤、原文M网格；沪深300多空与上证50、中证500多头。
4. 第4章：十条多头规则、六种代表策略绩效及结论。

图1—32、表1—10的对应关系由运行程序生成，见[逐项映射](paper_mapping.md)。两张行情复盘图、分箱敏感性及核账辅助解释原文问题，不重新安排主章节。

主表无费，成本情景单边0.2%/0.3%；具体数据和实施差异见[方法](methodology.md)。不追求数值匹配率，不据样本结果更换主参数。

## 独立附录：固定规则延长样本与额外验证

入口`python research.py`，配置`rsrs/research_spec.py`中的SPEC，结果`report/research/report.md`。保留10个多头、6个多空规则组合、同参数对照和3基线，共20条规则；其中原文单独展示的多空只为价格过滤右偏，其他多空组合属于附加覆盖。

附录费用统一单边0.1%，原报告期与发表后不变；N/M、阈值、预热、均线端点、量窗口、成交时点、缺失处理及期末处理均保持不变。完整历史连续运行后切片，不在分期边界重置仓位。

分期：原期2005-04-08—2017-04-28；发表后2017-05-02—2026-10-21；另列2017—2021、2022年以来及2026年内。2026年非完整年度优先看累计收益。

额外指标检验包括逐日Pearson/Spearman、1/5/10/20日期限、0/1日收益起点、HAC和同分期120项主检验的Holm校正。标签终点不得越过分期。分箱和非重叠分组仍属同一历史样本，不算独立重复。

成对移动块bootstrap仅评价发表后日均收益差×252，不是CAGR差或原期策略显著性证明。实施敏感性不回填主参数；完整预热600个β带来的收益变化需如实披露。此为回顾性研究协议，不声称事前注册。

## 验证与再现

`python tests/test_rsrs.py`、`python tests/test_research.py`、`python tests/test_paper.py`验证有手算答案的计算。`python check_replication.py`核查图表覆盖、数据和文件哈希、交易统计一致性与独立核账。CI重算原文主报告，不要求外部账户或网络行情。
