# 参考实现与取舍

原始依据是光大证券2017-05-01研报。公开实现参考：[QuantsPlaybook RSRS notebook](https://github.com/hugo2046/QuantsPlaybook/blob/master/C-%E6%8B%A9%E6%97%B6%E7%B1%BB/RSRS%E6%8B%A9%E6%97%B6%E6%8C%87%E6%A0%87/py/RSRS.ipynb)。本项目独立实现代码，不打包该notebook或复制其图表输出。

| 内容 | 参考实现的做法 | 本项目处理 |
| --- | --- | --- |
| 章节 | 基本跟随原研报概念、策略、指标修正与量价过滤 | 原文1—4章、32图10表逐项建清单 |
| 未来收益分箱 | `pd.cut(...,50)` | 采用50等宽箱作为明确约定；箱中点作横坐标，保留样本数 |
| 预测末端 | 上涨统计对缺失未来收益仍作比较 | 先排除不足10日的标签，避免把未知当下跌 |
| 标准化预热 | 零填充与完整rolling窗口；作者也讨论与原文扩展预热不同 | 缺失β不填0；不足M用已有有效值，最少10个为明确假设 |
| 费用 | 按指数成分权重均值近似，依赖聚宽 | 按指数目标暴露换手收费，公开单边与双边换算 |
| 年化与交易 | 各函数使用244/250等年化值，部分交易收益求和 | 统一252；交易收益按收益段复合 |
| M扫描 | 三种指标净值取均值；相关性分支调用`Add_MA` | 单独明确标准分族；量过滤实际调用量相关规则，三个指标不混合平均 |
| 样本 | 扩展至2019年的聚宽数据 | 主文按研报月度范围，公开实际数据缺口；延长样本另列 |

原文自身也存在待解释项：表7未明确变体，图32标题与六策略图例不符，价格过滤解释段与逐条规则的日期措辞不同。本项目均在相应章节披露。不能把公开参考代码或原文排版当成免检的规则来源。
