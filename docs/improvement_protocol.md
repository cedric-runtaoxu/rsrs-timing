# RSRS失效诊断与改进研究方案

本阶段与原研报复现分开。研究目标是评价固定规则在完整延长样本中的表现，解释有效性为何变化，并检验可解释的改进；不修改主复现报告中的规则和结果。

改进研究是在已经观察到2017年后表现的情况下开展的，候选结构与主参数选择参考了历史结果。因此2017—2026属于后验研究区间，不称为事前注册的盲样本外。所有计算只使用当日及此前数据，策略条件在评价期内保持一致。

## 时间口径

- 原报告期：2005-04-08至2017-04-28，仅用于建立参照。
- 延长样本全期：2017-05-02至2026-10-21，是唯一主要评价期。
- 延长样本前半段：2017-05-02至2021-12-31，只用于解释表现路径。
- 延长样本后半段：2022-01-01至2026-10-21，只用于解释表现路径。

指标使用原报告期及更早历史完成预热，进入延长样本后不重置滚动窗口或持仓状态。分段只切分收益评价，不改变参数、信号、执行、费用或过滤条件。

## 对照与候选

统一次日收盘执行、单边成本0.1%、现金收益0：

1. 买入持有。
2. 原始右偏RSRS(18,600,±0.7)。
3. 原研报价格过滤右偏RSRS。
4. 波动钝化RSRS(18,600,±0.7)，用波动率分位数调节R²惩罚强度。
5. 纯MA250趋势，用于识别改进是否只是均线效应。
6. 状态自适应RSRS：右偏RSRS的756日分位数，80/20开平仓区域，MA250与20日均线斜率约束。

## 失效诊断

- 指标与次日执行后未来10日收益的Pearson、Spearman相关。
- 分期交易胜率、平均收益、持有期。
- 空仓期间错过的正收益、规避的负收益及交易成本。
- 年度收益、仓位、回撤和换手。

## 稳健性

- 完整披露滚动窗口600/756/1000、趋势窗口200/250/300、分位区域70/30、80/20、90/10的27组邻域，并全部以延长样本全期为主要评价期。
- 主配置有经济解释，但不是预注册参数；完整邻域用于披露选择风险。
- 同一配置直接迁移到上证50和中证500，不按市场调参，评价期仍为2017-05-02至2026-10-21。
- 对改进策略与原价格过滤右偏策略在完整延长样本中的日收益差做30/60/120日移动块bootstrap。

这些检查只能降低数据挖掘风险，不能把历史回测变成未来收益保证。
