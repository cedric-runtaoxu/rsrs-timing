# RSRS失效诊断与改进研究方案

本阶段与原研报复现分开。研究目标是解释固定规则在发表后为何衰减，并检验可解释的改进，不修改主复现报告中的规则和结果。

本研究在已经观察到2017年后失效的情况下开展，候选结构与主参数选择参考了历史结果。以下时间隔离用于统一比较和防止计算穿越，不把2017—2026称为事前注册的盲样本外。真正的前瞻检验从2026-10-22以后开始。

## 时间隔离

- 开发期：截至2017-04-28，用于提出经济逻辑与检查实现。
- 2019报告跟踪期：2017-05-02至2019-11-13，仅用于对照作者后续报告。
- 2019报告发表后：2019-11-14至2026-10-21，是作者当时未见的后续区间；对当前研究仍属于已观察历史。
- 近期：2022-01-01至2026-10-21，观察当前市场结构下的表现。

不利用2017年后的收益重新估计RSRS的N、M或预测回归。自有方案的滚动分位数每天只使用当日及此前指标值；但研究设计和参数选择本身属于后验过程。

## 对照与候选

统一次日收盘执行、单边成本0.1%、现金收益0：

1. 买入持有。
2. 原始右偏RSRS(18,600,±0.7)。
3. 原研报价格过滤右偏RSRS。
4. 2019波动率钝化公式，继续使用18/600/±0.7，避免把作者利用截至2019年数据选出的18/700当成2017年后的独立样本外参数。
5. 纯MA250趋势，用于识别自有改进是否只是均线效应。
6. 状态自适应RSRS：右偏RSRS的756日分位数，80/20开平仓区域，MA250与20日均线斜率约束。

## 失效诊断

- 指标与次日执行后未来10日收益的Pearson、Spearman相关。
- 分期交易胜率、平均收益、持有期。
- 空仓期间错过的正收益、规避的负收益及交易成本。
- 年度收益、仓位、回撤和换手。

## 稳健性

- 完整披露滚动窗口600/756/1000、趋势窗口200/250/300、分位区域70/30、80/20、90/10的27组邻域。
- 主配置有经济解释，但不是预注册参数；完整邻域用于披露选择风险。
- 同一配置直接迁移到上证50和中证500，不按市场调参。
- 对改进策略与原价格过滤右偏策略的日收益差做30/60/120日移动块bootstrap。

这些检查只能降低数据挖掘风险，不能把历史回测变成未来收益保证。
